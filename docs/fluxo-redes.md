# Entrada pelas redes e contato

## Endereço para a bio

`https://breno-j-oliveira.github.io/Portfolio-Galaxia/links.html`

A página apresenta nome, foto, foco Full Stack e cinco destinos. O visitante escolhe conhecer projetos, consultar o resumo profissional, conversar sobre uma vaga, solicitar um projeto ou explorar repositórios. Os perfis sociais não foram alterados automaticamente.

## Contato

E-mail e LinkedIn são os canais profissionais principais. GitHub identifica o código; Instagram leva ao perfil pessoal. Cada link externo informa o destino, abre em nova aba e usa `noopener noreferrer` quando aplicável. Não há WhatsApp inventado, chat automático, métricas fictícias ou mensagens enviadas sem ação do visitante.

O assunto de oportunidade esconde orçamento. Pedido de projeto mostra orçamento opcional. A troca de assunto preserva a mensagem. O formulário prepara o rascunho e apresenta um botão explícito para abri-lo no aplicativo de e-mail. Não existe confirmação falsa de envio.

## Compartilhamento

As páginas principais têm URL canônica e imagem de compartilhamento. O botão de preferências permite compartilhar/copiar o endereço de entrada. Os casos usam `?project=...`; o catálogo preserva busca, linguagem e origem em parâmetros próprios, sem interferir nos casos selecionados.

Não há rastreamento de visitantes nem envio de dados para serviços de analytics. Favoritos e preferências ficam no navegador; dados de contato só são salvos quando o visitante ativa o rascunho.
